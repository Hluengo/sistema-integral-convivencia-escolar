# Instrucciones de OpenCode para el proyecto

- Idioma obligatorio: responde siempre en espanol de Chile. Incluye resumenes, explicaciones, errores, planes, comentarios de codigo y mensajes de commit.
- Antes de codificar, lee los archivos relevantes del proyecto y reutiliza patrones existentes de React, Vite, Supabase, Express, zod, TanStack Query y Zustand.
- Ahorra contexto: responde conciso, reutiliza skills y memoria antes de pedir contexto, y carga solo los MCP necesarios para la tarea.
- Flujo de trabajo: arquitectura breve, implementacion minima, verificacion proporcional con lint, typecheck o tests cuando corresponda.
- Seguridad: nunca expongas secretos. Usa variables de entorno. `SUPABASE_SERVICE_ROLE_KEY` solo debe usarse en servidor.
- Presupuesto MCP: manten maximo 10 servidores habilitados por proyecto. Deja en `enabled:false` lo que no uses.
