# Guía de documentación

Este índice facilita encontrar la documentación según la tarea. El [README principal](../README.md) presenta la plataforma y explica cómo iniciar el proyecto.

| Necesitas… | Empieza por… |
| --- | --- |
| Comprender el sistema | [Arquitectura general](architecture/00-overview.md) y [vista del proyecto](architecture/project-overview.md). |
| Conocer las decisiones técnicas | [Registro de decisiones](adr/) y [manual de ingeniería](engineering/HANDBOOK.md). |
| Configurar o desplegar | [Guía de despliegue](DEPLOY.md) y [procedimientos operativos](operations/). |
| Revisar seguridad y permisos | [Seguridad](architecture/security.md), [permisos](architecture/06-permissions.md) y [constitución del proyecto](CONSTITUTION.md). |
| Consultar antecedentes normativos | [Referencias normativas incorporadas al repositorio](leyes/). |
| Entender el trabajo pendiente | [Hoja de ruta](architecture/future-roadmap.md) y [revisiones técnicas](reviews/). |

Los archivos fechados en `operations/` y `reviews/` registran trabajos y evaluaciones de momentos concretos. Antes de usarlos para tomar decisiones actuales, contrasta sus conclusiones con el código y la configuración vigente. Las referencias en `leyes/` tampoco sustituyen la consulta de los textos oficiales actualizados.
